# Polite Book Scraper

## Target Classification

* **Target Site**: Books to Scrape (`https://books.toscrape.com/`)
* **Purpose**: Sandbox website designed specifically for practicing web scraping techniques safely without impacting production systems.
* **Scope**: First 3 catalogue pages (60 total book items).
* **Data Collected**: Title, product URL, raw price text, normalized numeric price (GBP), availability text, rating text, description, source page URL, and fetch timestamp.
* **Robots.txt Check**: Checked `https://books.toscrape.com/robots.txt`. Result: No `robots.txt` file found (404).
* **Ethics & Permission Declaration**: The site explicitly states it is a public sandbox built for scraping practice. I will not reuse this code on another site without checking its rules and terms first.
